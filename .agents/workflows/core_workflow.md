# Agent 核心开发工作流与协作规范 (Core Workflow)

本文档是 AI Agent 与人类协作时的**核心行为准则、交互流程与代码开发约束的唯一归属文件**。

---

## 1. 强制第一动作：前置阅读索引 (Mandatory First Action)

- **严禁直接修改代码**：在处理与本项目相关的任何任务（新增功能、调整样式、排查 Bug、重构代码）时，**第一个工具调用绝对不允许在应用目录下盲读或修改源文件**；
- **首要动作必须阅读索引**：必须首先阅读总入口文档：
  - 文件路径：[.agents/START_HERE.md](../START_HERE.md)
  - 根据索引中给出的唯一技术归属文件定位查阅，先建立系统架构与低侵入约束视角，再开展具体工作。

---

## 2. 方案前置与用户阻断确认流程 (Plan Review Before Execution)

- **严禁擅自修改已有代码**：在修改任何已有文件或新增模块前，**必须先输出详细的变更方案与实施计划**；
- **方案必须声明上游文件改动行数**：实施方案中必须包含：
  - 功能背景与低侵入式架构设计；
  - **触碰的官方已有文件清单及预计改动行数**（必须严格符合 [low_intrusion_standards.md](low_intrusion_standards.md) 中规定的单行尾挂载契约）；
  - 验证步骤与影响范围；
- **必须停下等待用户确认**：输出方案后，**必须立即停止（STOP）工具调用并结束当前轮次**，等待用户的明确确认（如用户回复批准或指示推进）；
- 未经用户明确批准前，严禁调用写文件或编辑文件的工具修改代码。

---

## 3. 闭源阅读引擎禁读铁律 (No-Read Obfuscated Bundles Rule)

**严禁**尝试读取 `src/assets/lib/` 下的以下混淆/压缩文件：
- `kookit-extra.min.mjs`
- `kookit.min.js`
- `kookit-extra-browser.min.js`

这些是压缩打包后的产物，不可人类/模型阅读且会严重消耗上下文。如需查阅源码，请直接读取本地对应源码仓库（如 `D:\Project\kookit`、`D:\Project\kookit-extra`）。

---

## 4. 表达与文档格式规范 (No Mermaid Rule)

- **严禁使用 Mermaid 等任何图表**：无论在生成的文档、给用户的回复、实施计划还是提示词中，**一律不得使用 mermaid 代码块或图表**；
- **统一使用纯文字结构化表达**：所有逻辑拓扑、调用流程、时序流转一律使用纯文字分级缩进列表、ASCII 文本树、Markdown 表格或清晰的文本步骤进行描述。

---

## 5. 交付前工作区干净度审查门禁 (Clean Workspace DoD)

在任何任务宣告完成、向用户汇报成果或提出结束之前，**必须严格执行以下工作区自查门禁**：

1. **第一步：语法与类型自检**：
   - 编写 TypeScript/React 代码后，确保无语法报错，必要时运行测试命令（`yarn test`）；
2. **第二步：文档同步门禁**：
   - 若本轮任务涉及新增页面、单行挂载点激活或配置变更，**必须在同一任务中同步更新 [overview.md](../specs/overview.md) 注册表及对应 [features/](../specs/features/) 规格文档**；
3. **第三步：执行状态自查**：
   - 调用 `git status -s` 检查工作区全量差异；
4. **第四步：识别与清理脏项**：
   - 检查是否有未跟踪的测试临时文件、构建缓存或未忽略的文件；
   - 确认工作区内除经用户批准的正式修改外，没有任何临时产物残留后，方可向用户交付。
